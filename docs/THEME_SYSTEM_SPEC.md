# مواصفات نظام الثيمات والمحرر — البنود التسعة

## بند 1 — Blocks
- نظام بلوكات عام لكل الأقسام: كل قسم يقبل blocks مرتبة من أنواع مسجلة في registry مشترك
- لكل بلوك: zod schema + defaults + نموذج إعدادات تلقائي (نفس آلية أقسام FieldMeta)
- يُطبق أولاً على main-product و hero (عناوين فرعية، أزرار، صور، شارات كبلوكات)

## بند 2 — قوالب الصفحات + صفحات الهبوط + الجدولة
- قوالب إضافية لكل نوع صفحة + صفحات هبوط مستقلة (صفحة مخصصة بقالب أقسام)
- جدولة نشر: تاريخ بداية/نهاية، ثيم مؤقت يرجع بعده للأساسي تلقائياً

## بند 3 — الأقسام الجديدة
- كل قسم جديد يدعم البلوكات + أنظمة الألوان + التحكم حسب الجهاز من أول يوم
- (تفاصيل الأقسام تُضاف لاحقاً — تُسجل في registry بملف واحد)

## بند 4 — الهيدر والفوتر والقوائم
- هيدر قابل للتكوين (شعار، قوائم، بحث، أيقونات) + فوتر بأعمدة وروابط قانونية/تواصل
- القوائم من بيانات Menu (الموجودة) — الهيدر/الفوتر يقرآنها

## بند 5 — Theme Settings (أساس)
- أنظمة ألوان متعددة لكل قسم (color schemes): لكل نظام مجموعة توكنات (خلفية/نص/أزرار)
- خطوط (عنوان/نص)، زوايا، تباعد، كثافة الصفحة — تُفرض عبر CSS vars على الجذر

## بند 6 — التحكم حسب الجهاز (أساس)
- إعدادات لكل قسم/بلوك قابلة للتخصيص لكل جهاز (mobile/tablet/desktop): إظهار/إخفاء + حقول مختارة (نص، عدد أعمدة، padding)
- آلية: settings overrides `{mobile:{...},tablet:{...}}` تُدمج حسب جهاز المعاينة/العرض

## بند 7 — أدوات المحرر
1. اختيار بيانات المعاينة: منسدلة لاختيار منتج/تصنيف/صفحة + معاينة كـ (عميل جديد/مسجل/سلة فيها منتجات)
2. رابط مشاركة معاينة: يفتح المسودة بدون دخول، صالح 7 أيام، شريط «معاينة — غير منشور» + زر إلغاء
3. مكتبة الوسائط: رفع متعدد بالسحب، بحث، فلترة (نوع/مستخدم/غير مستخدم)، قص بنسب جاهزة (1:1،4:5،16:9،حر) + نقطة تركيز، نص بديل عربي+إنجليزي، تنبيه >500KB + زر ضغط
4. إدارة الثيمات: نسخ/إعادة تسمية/حذف (غير المنشور)، تصدير/استيراد JSON مع تحقق schema ورسائل أخطاء
5. Presets: لكل ثيم presets (افتراضي، رمضان، اليوم الوطني، فخم، بسيط) — تغيّر الألوان/الخطوط/الصور الافتراضية فقط + حفظ نسخة قبل التطبيق
6. «صمم لي بالـ AI» (واجهة فقط): مدخلات (شعار اختياري، وصف النشاط، الطابع، الجمهور) → 3 اقتراحات (ألوان+خطوط+ترتيب+نصوص) بمعاينة وتطبيق كمسودة + «اكتب لي النص» بجانب الحقول النصية
7. لوحة جودة التصميم: تنبيهات (صورة ثقيلة، تباين ضعيف، إنجليزي ناقص، بلا نص بديل، قسم فاضي، رابط مكسور، زر بلا رابط) — كل تنبيه يحدد القسم في المعاينة + مؤشر أداء تقديري (سريع/متوسط/بطيء)
8. التعديل والتنقل: تراجع/إعادة ✓، حفظ تلقائي كل 5 ثوانٍ بـ«محفوظ ✓»، تحديد قسم/بلوك من المعاينة، إطار+اسم عند المرور، نسخ/لصق قسم بين القوالب، اختصارات (Delete، Ctrl+D تكرار، Esc إلغاء تحديد)
9. سجل النسخ: كل نشر=نسخة (تاريخ/ناشر/ملاحظة) + معاينة واستعادة كمسودة
10. الجدولة: نشر مجدول بتاريخ/وقت + ثيم مؤقت (بداية/نهاية) يرجع تلقائياً

## بند 8 — مميزات المتجر
1. المفضلة: قلب على البطاقة والمنتج + /wishlist + حفظ محلي للضيف ينتقل عند الدخول + عداد بالهيدر
2. المقارنة: حتى 4 منتجات بنفس التصنيف، شريط سفلي، صفحة جدولية
3. التقييمات: نجوم على البطاقة/المنتج، قسم تقييمات (متوسط، توزيع، فلترة، ترتيب)، كتابة بعد التوصيل فقط (نجوم+نص+حتى 5 صور) + «مشتري موثق» + رد التاجر + شاشة إدارة في لوحة التاجر (قبول/إخفاء/رد)
4. عرض سريع من البطاقة (نافذة: صور/سعر/خيارات/أضف للسلة)
5. شاهدتها مؤخراً: آخر 10، قسم قابل للإضافة
6. زر شراء ثابت على الجوال (يظهر بعد اختفاء الأصلي، فيه السعر والخيار)
7. مؤشرات ندرة: «باقي X» تحت حد يحدده التاجر + «X يشاهد الآن» (اختياري بإعداد)
8. تقدير التوصيل حسب مدينة العميل (تلقائي أو اختيار) من إعدادات الشحن
9. دليل مقاسات بجدول لكل تصنيف/منتج في نافذة
10. «أعلمني عند التوفر» للنافد برقم جوال + عداد المنتظرين في لوحة التاجر
11. أقساط: «4 دفعات بـX» تحت السعر بشعارات تابي/تمارا (واجهة)
12. مشاركة: WhatsApp/X/نسخ الرابط + صورة مشاركة لكل منتج
13. فلاتر متقدمة: شرائح قابلة للحذف، عداد لكل خيار، «مسح الكل»
14. تنقل: breadcrumb، سابق/تالي في التصنيف، زر لأعلى
- كل ميزة لها مفتاح تشغيل في إعدادات الثيم + حقول SCREENS_SPEC + رسائل UI_MESSAGES

## بند 9 — التوثيق والتغطية
- تحديث SCREENS_SPEC/UI_MESSAGES بكل الجديد
- كل السيناريوهات الجديدة في e2e + تقرير COVERAGE

## قواعد ثابتة
- registry واحد: قسم/بلوك جديد = ملف واحد (component + schema + defaults + FieldMeta)
- كل قسم: عربي+إنجليزي، جوال، كل أنظمة الألوان
- الثيمات الثلاثة تُحدّث + presetين لكل ثيم (رمضان + اليوم الوطني)
- النوافذ والعناصر العائمة lazy بعد تحميل الصفحة
- خطة التنفيذ بالترتيب: أ (5→6→1) · ب (4→2) · ج (3) · د (7) · هـ (8) · و (9+e2e+COVERAGE)
